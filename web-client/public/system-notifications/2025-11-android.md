# Host Beggar on Android!

How to use:

1. [Download this build](https://1drv.ms/u/c/83c52b42e4822761/EcRdPTgOS1FEhau8cakphtwBXdw1DDY_jbsNwfxUUM058Q?e=ICiJNG) and install the [SkyEmu](https://skyemu.app/) APK.
2. Put [`virtual_rom.gba`](virtual_rom.gba) in your phone's `Download` folder.
3. Connect the Host Beggar to your phone with a USB-C to USB-C cable or another OTG adapter.
4. Open SkyEmu, grant USB permission, then select `virtual_rom.gba` to start playing.
